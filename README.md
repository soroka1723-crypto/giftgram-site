# Gift gram — сайт

Одностраничный сайт (landing) про **Gift gram** — свободный мессенджер, по сути копия Telegram:
общайся, ищи друзей, продавай и делай что хочешь.

Официальный канал с информацией: **https://t.me/Giftgrammmmmm**

## Что внутри

- `index.html` — весь сайт в одном файле (HTML + CSS + JS, без сборки и зависимостей)
- Тёмная тема по умолчанию + переключатель на светлую (кнопка 🌙/☀️ или клавиша `T`), выбор сохраняется в `localStorage`
- Анимации: прелоадер, живые градиентные орбы, сетка, частицы на `<canvas>`, курсор-подсветка, параллакс мокапа телефона,
  печатающийся текст, счётчики, reveal при скролле, магнитики на кнопках, 3D-наклон карточек, бегущая строка, аккордеон FAQ,
  прогресс-бар скролла, кнопка «наверх», тосты
- Адаптив (desktop → планшет → телефон) и поддержка `prefers-reduced-motion`

## Как открыть

Просто откройте `index.html` двойным кликом в браузере. Локальный сервер не нужен.

Если хочется через сервер:

```bash
python -m http.server 8080
# затем http://localhost:8080
```

## Публикация на GitHub Pages

1. Запушьте репозиторий на GitHub (ветка `main`)
2. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `root`
3. Сайт будет доступен по адресу `https://<username>.github.io/<repo>/`
